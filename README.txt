# Website Devataru Creation

Website profil sederhana untuk CV. Devataru Cipta Kreasi.

## Cara menjalankan
1. Simpan `index.html` dan `style.css` dalam satu folder.
2. Buka `index.html` di browser.
3. Untuk dipasang online, folder ini dapat di-upload ke layanan hosting seperti Vercel, Netlify, atau GitHub Pages.

## Yang perlu diganti
- Nomor WhatsApp `6281234567890` pada `index.html` dengan nomor WhatsApp Devataru yang benar.
- Foto pada bagian galeri dengan foto asli usaha.
- Nama, deskripsi, layanan, dan informasi kontak jika ada perubahan.
- Link Instagram jika sudah tersedia.

## Catatan
Alamat dan nomor telepon pada halaman dibuat berdasarkan informasi yang terlihat pada gambar pengguna. Nomor WhatsApp masih berupa contoh/placeholder dan harus diganti sebelum dipublikasikan.
